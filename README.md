# demos

Reproducible experiments and demos by Gabriel Alexander.

Each directory is a self-contained project with its own README, dependencies,
and run instructions.

| Demo | What it does |
|---|---|
| [same-question-100-times](same-question-100-times) | Runs one customer support question through an LLM agent 100 times and measures correctness, cost, latency, and faithfulness with a three-layer eval suite. |
